# Scholarship Miner

A modern scholarship discovery website built with React and Tailwind CSS.

Scholarship Miner helps students search, filter, explore, and save scholarship opportunities through a clean and responsive interface.

## Features

- Responsive scholarship discovery UI
- Scholarship search
- Filtering by country, degree, field, and funding type
- Sorting and pagination
- Scholarship details
- Save and remove scholarships
- Saved scholarships with localStorage
- Direct application links
- Responsive layouts for desktop, tablet, and mobile
- Smooth page navigation
- How It Works and About pages

## Tech Stack

- React
- React Router
- Tailwind CSS
- Context API
- localStorage
- Vite
- Lucide React
